# Onadit

Smart, local memory for all your agents. Onadit keeps your AI conversations on
your Mac, so the agents you connect can look up what you already worked out.

- Download: [onadit.com/download](https://onadit.com/download), or the latest
  installer under [Releases](https://github.com/clementrog/onadit/releases/latest)
- Docs: [onadit.com/docs](https://onadit.com/docs)

The installer is for Apple Silicon Macs. It is signed with a Developer ID
certificate and notarized by Apple. Each release lists its SHA-256.
